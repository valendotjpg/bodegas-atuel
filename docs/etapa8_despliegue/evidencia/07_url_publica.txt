== Conectividad desde otros dispositivos ==
Verificado por el grupo: los integrantes abren la URL desde dispositivos propios
(fuera de la red del host), cumpliendo "cualquier persona puede abrir la URL
publica y usar el sistema". Sobre el plan Free de Render el servicio entra en
cold start tras 15 min sin uso: el primer request luego tarda 30-60 s.

== Conexion cifrada a la base ==
El DSN de la API exige sslmode=require (channel_binding=require): si la
conexion no es TLS, el servidor la rechaza. El pool usa el endpoint pooled de
Neon (ep-...-pooler.c-2.sa-east-1.aws.neon.tech).
